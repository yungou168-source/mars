# SNF Lottery Plugin

National lottery system for the Sovereign Nation Framework — weekly draws, prize pools, transparent on-chain results.

## Features

- Weekly national lottery draws with transparent RNG
- Multiple prize tiers (jackpot, second tier, third tier)
- Prize pool funded by ticket sales
- Historical draw results with verifiable on-chain proof
- Automatic prize distribution

## Usage

```typescript
import { createLotteryPlugin } from '@sovereign-nation/snf-lottery';

const plugin = createLotteryPlugin();
```
