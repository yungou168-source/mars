# SNF Bounty Plugin

Task bounty board for the Sovereign Nation Framework — post bounties, claim tasks, earn rewards.

## Features

- Post bounties with configurable rewards and deadlines
- Claim tasks and track completion status
- Multiple bounty categories: bug bounty, citizen mission, research, creative
- Reputation system for bounty hunters
- Escrow-based reward distribution

## Usage

```typescript
import { createBountyPlugin } from '@sovereign-nation/snf-bounty';

const plugin = createBountyPlugin();
```
